# [GPS]手順_GPSログと写真のEXIF情報をリンク

GPSログと写真のEXIF情報をリンクさせて保存

## １．方法１

1. `MtkDLut.exe`　ログの読み込み(TRL)
2. `NMEA2KMZ.exe`　ファイル変換(TRL→GPX)
3. kasimir 時刻でGPSと補間推定→JPG書き込み

- カメラとGPSの時刻ずれの補正方法が不明

## ２．方法２★おすすめ

GeoSetterを使用

1. 画像ファイルを選択
2. GPSデータ同期（設定）
3. 一覧で時刻の確認（撮影、GPS差分ほぼゼロ）
4. 地図確認
5. 変更を保存（元ファイルは`.original`）
6. 「撮影日付をファイル日付に設定」でタイムスタンプに反映

## ３．方法３

GMMを使用

1. 時刻補正(GPSログの時刻の値に設定、GMT０Hにする)
2. GPSログをドラッグして読み込み
3. 写真をドラッグして読み込み
4. 写真を選択して一括ジオタグ書き込み＆保存
5. 時刻情報がずれているのはエラーとなるので、時刻補正で修正
6. 撮影日時をファイル日時に修正

## ４．方法４

カシミール

3. カシミール３Ｄを起動
4. 「ファイル」→「ＧＰＳ各種ファイルを読む」を選択し、ＧＰＳのデータを読み込む
5. 「ツール」→「デジカメプラグイン」→「ブラウザ起動」を選択
6. デジカメプラグインが表示されたら、「フォルダ一覧」から自分が保存した画像のフォルダを選択。次にその下に表示される「名前」から表示させたい画像を選択
   - ※複数選択する場合はコントロールを押しながら選択
7. 「ＧＰＳデータから位置を推定する」を選択
8. 選択した写真が地図上にプロットされる
   - ※この時点ではまだ地図情報は写真に書き込まれていない
9. 書き込みたい写真を選択
   - ※複数選択する場合はコントロールを押しながら選択
10. 写真の下にあるアイコンのうち「アイコンの位置をＥｘｉｆとして書き込む」をクリック
