# [GPS] 手順_やまやまGPSでDIY地図、ルートを作成し使用する

## サマリ

1. DIY地図の作製方法は
   - カシミール３Dで地図画像を取り込み、位置情報を合わせて、→0章
   - kmzにまとめて出力　→2章
   - (小さいマップではここまで、さらに大きい場合はタイル化必要)
   - 「DIY MAP　Maker」でタイルDBにする　→3章
2. ルート(gpx)の作製は、
   - カシミール３D上でポイントを指定しルートを作成
   - 出力。

## 手順説明

### 0章)配布資料からのルート作成

- ビットマップで地図を読み込む(JPGでよい)
- 地図の目印ポイント3か所のGPS位置情報を取得する
  - 右クリック→位置のマーク→緯度経度を目盛る
- ビットマップ読み込み：ファイル→地図を開く→新規地図
  - 「開く」→「形式を指定した地図」→「ビットマップ地図」
- 編集→地図のキャリブレーション
  - 3か所の緯度経度を設定する

### 1章)ルートの作成方法

カシミール上で作成

- 地図上で右クリック
- 新規作成→トラック作成(ルート作成でもよい)
- 地図上でトラックをプロットしていく。
- 最後に「確定」
- 名前を付けて保存　コースルート
- 「ルート作成」で作った場合は、トラックに変換する。

→出力ファイル　gpx　(kmlは全体のGPS位置が入っていない)

### ２章）オフライン地図の作製

- タイルマップ(標準の地理院地図でもよい)選択。
- 出力範囲の指定(編集→洗濯範囲を決める)
- 表示倍率を合わせる。オフラインにインタネットより読み込む。
- すべてがキャッシュに入ったら、その倍率のままで、ツール→マップカッター→切り出し
- GPSトラックを入れるなら、「表示」にしておくこと。
- 画像は１枚にすること。

→出力ファイル　kmz

mapの最大サイズの目安。

- 1000万画素(iPhone4、第4世代iPod touchなど)
  - 3200x3000、4000 x 2500、6000 x 1600、8000x1200
- 1600万画素(iPhone4S以降)
  - 3000x5300、4000 x4000、6000 x 2600
- 5000万画素(iPhone5以降)
  - 8000x6250、12500 x4000、7000 x 7142

小さいマップではこのサイズに収まるが、それ以上の範囲ではタイル化が必要→3章

### ３章）タイルDBへの変換

※DIY MAP Makerはインストールして使用しないとRenderingでエラーとなります。

2章で出来上がったkmzファイルには、地図画像と位置設定データの2ファイルでzip化されたものである。

- `custom_map.jpg`
- `doc.kml`

DB(.diymap)変換には「DIY Map Maker」を使用する。

起動後、Continueののち、

- Source data file -> kmzファイルを指定
- Spatial reference system(SRS) -> WGS84のまま
- ContinueDetails about the tile pyramid ->　Zoom Level(12-16),Format（PNG)はそのまま
- Destination Folder→そのまま(変更可）
- いくつかContinueののちRederingが開始される。
- 終了すると、出力フォルダーが表示される

出力フォルダーには、途中段階で生成したタイルファイルとDB(.diymap)が出来上がっている。必要なのでDBのみなのでこれをリネームして取り出す。

- `custom_map.diymap　→　地図名前.diymap`

ほかのタイルデータは、もう必要ないので削除可能

### ４章）やまやまGPSへ送信(iTunes、Dropboxなど経由）

- ルート　→　.gpxファイル
- DIY地図　→　.kmz　または　.diymap
