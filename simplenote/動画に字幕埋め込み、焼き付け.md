## 字幕焼き付け2026.bat

```bat
: 動画に字幕ファイル(SRT)を焼き付けて出力する
:　Usage:　　字幕焼き付け.bat [P1]
:　入力；
:　　P1　動画ファイル名フルパス(mp4等)
:　　　　指定しない場合はプロンプトから入力
:　　P1で指定した動画ファイル名と同じフォルダにある
:　　.srtファイルを字幕ファイルとしてみなす
:　出力：
:　　output.mp4　上書き防止のため固定ファイル名
:　オプション：
:　　１）エンコードついでにオーディオコーデックをmp3に変換
:　　　(無効化するのであればコメントアウト）
:　　2)ビットレート制御　1Mbpsに設定中
:::::::::::::::::::::::::::::::::::::::::::::::::::::::::
       SET INPUT=%~1
       IF "%INPUT%_" == "_" set /P INPUT="★ファイル="
       CALL :INPUT_SUB %INPUT%
SET FILEPATH=%_FULLPATH%
:カレントディレクトリで処理
pushd %FILEPATH%
       :使用するパターン
       SET FILEPATH=
       SET FILENAME=%_NAME%
       SET FILEEXT=%_EXT%
       set INPUT=%FILEPATH%%FILENAME%%FILEEXT%
       set SUBTITLE=%FILEPATH%%FILENAME%.srt
       set OUTPUT=output.mp4
:::::::::::::::::::::::::::::::::::::
:設定各種
 :出力形式
       :字幕焼きこみ
       :SET OUT_FORMAT=-vf subtitles="%SUBTITLE%"
       :字幕焼きこみ＋画像サイズ変更（ffmpeg -i in.mp4 -vf scale=1280:-1 out.mp4）
       SET OUT_FORMAT=-vf "subtitles=%SUBTITLE%,scale=-1:480"
       :SET OUT_FORMAT=-vf "subtitles=%SUBTITLE%,scale=640:-1"
       :SET OUT_FORMAT=-vf "subtitles=%SUBTITLE%,scale=320:-1"
 :ビットレート制御
       :SET BITRATE=
       SET BITRATE=-b:v 1M
 :音声形式
       :SET ACODEC=-c:a copy
       SET ACODEC=-c:a libmp3lame -b:a 192k
:::::::::::::::::::::::::::::::::::::
       if NOT EXIST "%INPUT%" goto :ERR
       if NOT EXIST "%SUBTITLE%" goto :ERR
       if "%INPUT%" == "%OUTPUT%"      set OUTPUT=%FILEPATH%\FILENAME%_new.mp4
       :変換実行
       :字幕焼きこみ
       echo ffmpeg -i "%INPUT%" %OUT_FORMAT% %ACODEC% %BITRATE% "%OUTPUT%"
            ffmpeg -i "%INPUT%" %OUT_FORMAT% %ACODEC% %BITRATE% "%OUTPUT%"
popd
pause
exit /b
:ERR
echo FILE NOT FOUND
popd
pause
exit/b
:===========================================================
::::SUB
:INPUT_SUB
:      P1 filename(full path)
: 返却値
       SET _FILENAME=%~1
       SET _EXT=%~x1
       SET _DNP=%~dnp1
       SET _NAME=%~n1
       SET _FILE=%~nx1
       SET _FULLPATH=%~dp1
       SET _PATH=%~p1
exit /b
:===========================================================
```

### ffmpegを使ってVTTファイルを動画ファイルに埋め込み

参考: <https://ytmt-stag.com/ja/post/00002_ffmpeg/>

あとはmp4とvttファイルを用い、以下のコマンドでmkvファイルを作成します。

```bat
ffmpeg -i [元動画].mp4 -i [ダウンロードしたvttファイル].vtt \
  -map 0:v -map 0:a -map 1 \
  -metadata:s:s:0 language=[英語ならeng/ 日本語ならjpn] \
  -c:v copy -c:a copy -c:s srt \
  [出力先].mkv
```

-mapで指定した0や1などは短縮形で、実際には-map 入力:ストリーム:出力:ストリームという指定になるそうです。[1] これで字幕のON/OFFを切り替えられるmkvファイルの出来上がりです。

### 音声

```bash
$ ffmpeg -i input.mp4 -i audio_jpn.mp3 \
  -map 0:v -map 0:a -map 1:a \
  -metadata:s:a:0 language=eng
  -metadata:s:a:0 title="Default" \
  -metadata:s:a:1 language=jpn
  -metadata:s:a:1 title="Japanese" \
  -c:v copy -c:a libopus multi-audio.mkv
```

```text
-------- 音声
  input        map     metadata        lang            title
 file[0]       0:v
               0:a     s:a:0           lang eng        Default
 file[1]       1:a     s:a:1           lang jpn        Japanese
--------
```

### 字幕

```bash
$ ffmpeg -i input.mp4 -i subtitle-eng.srt -i subtitle-jpn.srt \
  -map 0:v -map 0:a -map 1 -map 2 \
  -metadata:s:s:0 language=eng \
  -metadata:s:s:1 language=jpn \
  -c:v copy -c:a copy -c:s srt \
  multi-lang-subtitle.mkv
```

mkvとだいたい同じだが、mp4の場合は字幕形式がmov_textになる。

```text
-------- 字幕
  input        map     metadata        lang            title
 file[0]       0:v
               0:a
 file[1]       1       s:s:0           lang eng
 file[2]       2       s:s:1           lang jpn
--------
```

正式な指定は次の形式です。出力を省略したら、そのまま踏襲の意味になります。

```text
 -map 入力:ストリーム:出力:ストリーム

 例 映像１＋音声２
 file[0]       0
               1
 file[1]       0
                       1
 出力
       -map 0:0:0:0 -map 1:1:0:1
```

## ★srt_to_vtt.bat

```bat
SET CMDPATH=P:\APL\ffmpeg\bin
SET FFMPEG=%CMDPATH%\ffmpeg.exe
SET OUTPUT=%1
SET OUTPUT=%OUTPUT:.vtt=.dat%
SET OUTPUT=%OUTPUT:.srt=.vtt%
```

## TXT2SRT.TXT

```awk
# Streamerで作成されたトランススクリプトを字幕ファイルに変換する。
BEGIN{
       no=0;
}
#00:00
#はい、公共システム技術グループの児 島です笑防止霊能音声合成機能研究に
{
       if( no > 0){
         gsub(/ /,"");
         ENDTIME=$0;
         print no;
         printf("00:%s,010 --> 00:%s,000\n",STARTTIME,ENDTIME);
         print INTEXT;
         printf("\n");

         ;
       }
       gsub(/ /,"");
       STARTTIME=$0;
       getline;
       INTEXT=$0;
       no++;
}
END{
         ENDTIME=$0;
         print no;
         printf("%s - %s\n", STARTTIME, "99:00:00,000");
         print $INTEXT;
}
```
